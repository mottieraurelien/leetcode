# LeetCode

In this repository, you will find the top 50+ company-asked LeetCode exercises, regrouped and sorted by difficulty
(easy, medium and hard). This list has been provided by Gemini on 2026-10-27.

Unit tests have been written from the LeetCode cases (most). Passing whole set of unit tests will lead to an acceptable
solution on the LeetCode platform (submission).

You may start with the easy ones, but their sequence does not matter (the second easy problem is not easier than the
third one). If you feel comfortable with the easy ones, you may start the medium ones (even if the easy ones are not
done yet).

### Reminder

Difficulty is a matter of perspective (your level/knowledge), but also a matter of expectations from companies
interviewing candidates. I did not set the difficulty, LeetCode did. If a given "easy" problem is giving you headache,
then it's probably your improvement area you may need to focus on short/mid-term.

Below, you can find a submission number, the corresponding URL will be:

`https://leetcode.com/submissions/detail/{submission number}/`
